Petit script Node.js qui permet d’envoyer plusieurs fois un message à quelqu’un sur WhatsApp via WhatsApp Web.

---

## Installation

```bash id="bqk8m1"
git clone https://github.com/MhdxMx/Whatsapp_bot_for_spam_message.git
cd Whatsapp_bot_for_spam_message
npm install
```

---

## Lancer

```bash id="x7p3nd"
node index.js
```

---

## Connexion

Un QR code va s’afficher dans le terminal.

WhatsApp → Appareils connectés → Lier un appareil → scanner

---

## Utilisation

* numéro (sans +, format international)
* message
* nombre d’envois

---

## Attention

À utiliser avec modération.
Trop de spam = ban possible.
